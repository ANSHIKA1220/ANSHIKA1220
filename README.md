A record-linkage system for finding duplicate entities across disconnected departmental datasets. It uses Splink, candidate blocking and union-find clustering, achieving **100% precision, 89.3% recall and 94.3% F1** on synthetic evaluation data.

`Python` `Splink` `DuckDB` `FastAPI` `React` `Ollama`
